# 调研素材 — Garden Tower Defense Best Early Game Units

关键词：garden tower defense best early game units（分类：Early Game，排名类）

调研日期：2026-09-13

## 方法

新手真正能接触到的单位来自最便宜的 **Classic Summon**（100 单抽 / 900 十连，
游戏发布时就有的起始钥匙），而不是 Godly/Exclusive 那些高稀有度钥匙。本轮核实了
两个能从 Classic Summon 抽到的单位。

## 已核实：Farmer（Uncommon）—— `gtd.fandom.com/wiki/Farmer`
- Currently Obtainable: Yes，Classic Summon 抽取概率 **15%–17%**（新手很容易拿到）
- DPS：8 → 102，Damage：7 → 49，Range：6 → 10，Attack Speed：0.90 → 0.49
- Placement Cost：200（起始价很低，适合摆很多个）
- 上线时间：游戏发布不久后的"Mini Mid-Week QOL Update"

## 已核实：Sunflower（Legendary）—— `gtd.fandom.com/wiki/Sunflower`
- Currently Obtainable: Yes，Classic Summon 抽取概率 **0.99%**（比 Farmer 稀有得多，
  新手不一定马上拿到，但也是从最便宜的钥匙就能抽，不需要氪高级钥匙）
- DPS：32 → 397，Damage：45/120 → 700/1500（wiki 正文和升级表数字有一处不一致，
  已如实记录两个数字，标注待确认）
- Placement Cost：1200，Placement Limit：8
- 上线时间：2025-04-05 游戏首发版本（V1.0.0）就有

## 重要发现：Fandom wiki 对基础稀有度单位的页面还没写完

尝试查最基础的 **Tomato**（Common 档，游戏里最低稀有度之一）——页面是空的
（"There is currently no text in this page"）。说明这个 wiki 对低稀有度单位的
覆盖并不完整，很多"新手常见单位"暂时查不到官方数值，只能如实说明，不能编数字。

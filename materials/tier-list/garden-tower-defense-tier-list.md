# 调研素材 — Garden Tower Defense Tier List

关键词：garden tower defense tier list（分类：Tier List）
调研日期：2026-09-13

## 排查过的候选源，及为什么大多数不能直接用

1. **GameRant "Best Units in Roblox Garden Tower Defense"**
   (`https://gamerant.com/roblox-garden-tower-defense-best-units-tier-list/`)
   - 发布于 **2025-09-06**，距今已一整年，游戏每周六都有更新（见 site.config 里的
     "Weekly Updates: Sat 13:00 UTC"），大概率已过时。
   - 通篇给的是 S/A/B/C 分级表，**没有任何 DPS/成本/射程等具体数值**，只有"Golem 是
     最强 DPS"这类文字判断，找不到出处支撑，不满足用户四类标准里的任何一条。
   - **不采用其排名结论**，只作为"哪些单位值得关注"的线索来源。
   - 注意：WebSearch 自动摘要曾声称该文章给出"Golem 100-1300 DMG、Venus Flytrap
     80-600 DMG"，**实际打开原文后发现根本没有这两个数字，是 WebSearch 自己编的**。
     再次印证 WebSearch 摘要不可直接采信，必须打开原页面核对。

2. **TierMaker 社区投票榜**(`tiermaker.com/categories/roblox-games/garden-tower-defense-...`)
   - 是任何人可投票的公开小站，不是"官方 Discord / 官方 value list 页面"，
     不满足用户标准里的第 4 类"官方社区共识"，弃用。

3. **Garden Tower Defense Wiki（Fandom，`gtd.fandom.com`）—— 采用**
   - 真实存在的 Fandom 数据表型 wiki，`Towers` 页面把全部单位按稀有度分组：
     Common → Uncommon → Rare → Epic → Legendary → Godly → Exclusive（7 档）。
   - 里面出现的单位名（Blossom Barrage、Doompetal、Hellroot、Golem、Carrotastrophe、
     Rafflesia、Venus Flytrap、Mango Cluster、Electroleaf、Pesticider、Seed Mech、
     Atomic Pepper、Shadestool、Sporefang、Timekeeper、Rosebeam 等）与 Traderie 真实
     交易记录、gardentowerdefensevalues.com 的物品名高度重合，交叉印证为真实数据，
     不是编造的。
   - **稀有度本身就是用户标准里明确认可的客观数值来源（"游戏内客观数值：DPS/成本/
     射程/稀有度"）**，所以可以把稀有度分组直接当作 Tier List 的骨架来写。

## 单位详情页抓到的具体数值（Fandom，逐条有独立 URL 可查）

### Golem（Exclusive 档）—— `gtd.fandom.com/wiki/Golem`
- **Currently Obtainable: No** —— 已下架的限时绝版单位（2025-06-21"The Enchanted
  Update"上线，目前不可获得）。**这是关键事实**：很多第三方文章把 Golem 吹为最强
  DPS，却没提它现在根本拿不到，写 Tier List 正文时必须标注，否则会误导玩家去追一个
  拿不到的单位。
- DPS：93 → 2167（满级），Damage：275 → 3250，Range：15 → 41，Attack Speed：3 → 1.5
- Placement Cost：1325，Cost Efficiency：DPS / $1000 = 52
- 技能：投石头，命中晕眩敌人 0.5 秒

### Venus Flytrap（Godly 档）—— `gtd.fandom.com/wiki/Venus_Flytrap`
- **Currently Obtainable: Yes** —— 可通过 Enchanted Summon 钥匙（200/1800 货币）
  抽取，0.01% 概率。
- DPS：188 → 3750（满级），Damage：225 → 1500，Range：20 → 38，Attack Speed：3 → 1
- Placement Cost：2900，Cost Efficiency：DPS / $1000 = 71.9（比 Golem 的 52 更高）
- 页面最后更新：2026-04-25

## 待确认

- 除 Golem、Venus Flytrap 外，其余数百个单位的逐一 DPS/成本数值未全部核对（Fandom
  每个单位一个独立页面，全量核对成本过高，本轮只做了两个代表性案例）。
- 稀有度分组反映的是"获取难度/珍稀度"，不直接等于"战斗强度排名"——同一档位内谁更强，
  没有独立数值支撑前不应下结论。
- Fandom wiki 本身允许社区编辑（"community content"），个别数值可能有笔误，未做
  二次交叉验证。

## 建议正文写法

- 以 Fandom 的稀有度分档（Common→Exclusive）作为 Tier List 的骨架，标明来源
  （gtd.fandom.com/wiki/Towers）。
- 明确写清楚："稀有度不完全等于战斗强度，同档位内的具体强弱排序需要看每个单位的实际
  数值"。
- 对 Golem、Venus Flytrap 这两个具体案例，给出真实 DPS/Cost Efficiency 数字和
  Obtainable 状态，作为"如何用客观数值判断强度"的示范，而不是笼统断言。
- 其余单位排名维度标注"待确认"，不要照抄第三方过时的 S/A/B/C 榜。

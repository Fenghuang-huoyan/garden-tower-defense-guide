# 调研素材 — Garden Tower Defense Value List

关键词：garden tower defense value list（分类：Values）
调研日期：2026-09-13

## 结论摘要

Garden Tower Defense **没有游戏官方发布的价值榜**。市面上是多个玩家/第三方自建的
"value list" 追踪站，彼此数据不完全一致，这是 Roblox 交易类游戏的普遍现象（价值由
玩家交易共识决定，不是游戏内固定标价）。因此本页只能呈现"某个具名来源在某个时间点
的快照"，并标明数据可能随时波动，不能写成无出处的"确定排名"。

## 来源交叉核对过程

1. **候选源 A**：`https://sites.google.com/view/garden-td-values/`，自称
   "GARDEN TOWER DEFENSE OFFICIAL VALUE LIST"。
   - 检查了 Main Page，页面没有任何开发商关联/认证的证据，"OFFICIAL"是站点自己起的名字，
     不代表官方（不满足用户标准里的"官方社区共识"）。
   - Units/Gamepasses 页面列出的物品名（Glass Bamboo、Glass Sunflower 等）是数据表格式
     （23 页，按字母序），命名风格像是"全部基础单位图鉴"，**这批名字在 Traderie 真实
     交易记录里完全找不到对应项**。
   - **判断**：这个源大概率对应的是"全部单位"（Units 分类），不适合用在 Values 页面，
     已记录留给后续做 `garden tower defense all units` 时使用，本页不采用其数值。

2. **候选源 B**：`https://gardentowerdefensevalues.com`
   - 站内自己声明："fan-made site and is not affiliated with... Garden Tower Defense or
     Garden Defenders"（非官方，第三方粉丝站）。
   - 首页默认列表给出 20 个物品的 Value / Demand(1-10) / Status(Stable/Fluctuating/
     Rising/Dropping/Unstable) 快照（截至 2026-09-13 抓取时）。
   - 站点未标注具体的每周/每日更新时间戳，只在 FAQ 里写"daily"。

3. **交叉验证**：用 `https://traderie.com/gardentowerdefense`（Roblox 第三方 P2P 交易
   挂单市场，真实用户发帖，非价值榜，是真实"正在被交易"的物品清单）核对候选源 B 里的
   物品名是否真实存在于交易市场——
   - **命中（物品真实存在于实际交易挂单中）**：Blossom Barrage、Carrotastrophe、
     Electroleaf、Rafflesia、Hellroot、Doompetal、Mango Cluster、Petalray。
   - 结论：候选源 B 的物品清单是真实的游戏内物品，不是编造的。但 Traderie 上是以物易物
     的挂单（"1 X A 换 1 X B"），**没有标注统一的数值单位**，所以无法用 Traderie 逐一
     核实候选源 B 给出的具体数字（如"Blossom Barrage: 11.5k+"）是否精确，只能确认
     "这个物品真实存在且正在被交易"。

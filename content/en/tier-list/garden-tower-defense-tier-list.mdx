## Sort order: official rarity tier, not a strength ranking

This page uses the wiki's own rarity classification as its backbone (an objective in-game
attribute), not a numeric strength sort. For units ranked by actual numbers, see
[Best DPS](/best-dps/garden-tower-defense-best-dps-units) (pure DPS) or

## How this tier list is built

Most "tier list" articles for this game rank units with no stated evidence — just a writer's
opinion. This page instead uses the game's own Fandom wiki rarity classification as the backbone,
since rarity is an objective in-game attribute, not an opinion. Rarity is not the same as combat
strength, though: two units in the same rarity tier can perform very differently, and we only
make a strength claim when we have actual numbers to back it up.

## Three units checked in detail

These are the only three units where we pulled full stats and can make a sourced comparison —
the rest of the ~300+ unit roster has not been individually verified yet.

### Golem (Exclusive) — currently NOT obtainable

Golem gets recommended as a top DPS pick by several third-party sites, but its own wiki page
says **"Currently Obtainable? No"** — it was a limited-time exclusive from the June 2025
"Enchanted Update" and cannot currently be acquired. Don't build a strategy around chasing it.

| Stat | Value |
|---|---|
| DPS (level 1 → max) | 93 → 2167 |
| Damage (level 1 → max) | 275 → 3250 |
| Range (level 1 → max) | 15 → 41 |
| Attack Speed (level 1 → max) | 3 → 1.5 |
| Placement Cost | 1325 |
| Cost Efficiency (DPS per 1000 spent) | 52 |
| Ability | Throws rocks, stuns hit enemies for 0.5s |

### Venus Flytrap (Godly) — currently obtainable

| Stat | Value |
|---|---|
| DPS (level 1 → max) | 188 → 3750 |
| Damage (level 1 → max) | 225 → 1500 |
| Range (level 1 → max) | 20 → 38 |
| Attack Speed (level 1 → max) | 3 → 1 |
| Placement Cost | 2900 |
| Cost Efficiency (DPS per 1000 spent) | 71.9 |
| Obtain method | Enchanted Summon crate (200/1800 currency), 0.01% drop chance |

By cost efficiency (DPS per 1000 spent), Venus Flytrap (71.9) actually outperforms Golem (52) —
and unlike Golem, it's still obtainable. This is the kind of numeric comparison this page will
keep expanding as more units get checked.

### Rafflesia (Godly) — a third data point, and a different unit type

Rafflesia isn't a straightforward attacker — it's a trap that attaches to a mob as it passes,
drops back onto the track when that mob dies, and immediately reattaches. Despite the unusual
mechanic, the wiki gives it a full DPS/cost breakdown:

| Stat | Value |
|---|---|
| DPS (level 1 → max) | 120 → 1500 |
| Placement Cost | 1250 |
| Cost Efficiency (DPS per 1000 spent) | 162.2 — the highest of any unit checked so far |
| Obtain method | Mystery Trader shop, 20% stock chance, 75,000 currency or a real-money price |

This is a good illustration of why rarity tier alone doesn't predict value: Rafflesia sits in
the same Godly tier as Venus Flytrap and Bouncing Shroom, but has more than double Venus
Flytrap's cost efficiency.

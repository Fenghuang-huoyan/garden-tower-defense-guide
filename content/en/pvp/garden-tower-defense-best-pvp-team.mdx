## How PvP actually works

PvP is a 1v1 mode: both players build defenses and send enemies to each other's base at the
same time.

- A 60-second ban phase opens each match — each player can ban up to 5 units, bans are hidden
  from the opponent, and **Timekeeper is banned by default in every match**, ranked or casual.
- After bans, each player picks 5 units from their own inventory to bring into the match.
- The match runs like Classic Mode for 50 waves, then escalates into a "Tiebreak" phase where
  the enemies are Moth Overlords — **immune to stun effects**.
- Whoever's base survives longest wins; simultaneous losses are a draw.
- Ranked mode has 9 ELO tiers from Wood to Champions, each with its own reward tier.

## What the developers' own design tells you

- **Timekeeper is banned in every single match by default** — that's the developers themselves
  flagging it as strong enough to need a blanket ban, not a community opinion.
- **Stun-based crowd control loses value in the Tiebreak phase**, since Moth Overlords are
  immune to it. A unit like Golem, whose whole kit is a stun ability, would stop contributing
  crowd control once Tiebreak starts (and it's no longer obtainable regardless — see
  [Best Units](/best-units/garden-tower-defense-best-units)).

## This page doesn't embed a live calculator

We're not going to claim a feature this site doesn't have. What follows is an honest
explanation of how existing value calculators for this game work, and where to find one.

## How a Garden Tower Defense value calculator works

Checked directly against a live example (GardenTowerDefenseValues.com's calculator, titled
"Check Wins & Losses"): it's a two-column tool — "You" and "Them" — where you add the items
each side is offering. Each column totals up a Value score as you add items, and the comparison
tells you which side is coming out ahead in the trade.

## Before you trust a calculator's result

A calculator is only as reliable as the value table behind it, and — as covered on the
[Value List](/values/garden-tower-defense-value-list) page — Garden Tower Defense has no single
official value source. Different community trackers can disagree on a given item's number, so:

- Check which tracker's data the calculator is using, and whether it matches what you see on
  other trackers or on live Traderie listings (see [Trading](/trading/garden-tower-defense-trading-values)).
- Treat a "you win this trade" result as a starting point for negotiation, not a guarantee.
- Re-check high-value trades against more than one source before committing.

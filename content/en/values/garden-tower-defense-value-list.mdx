## How to read Demand, Status and Rarity

Per the source site's own explanation:

- **Demand** shows how many players are looking for an item. Higher demand trades faster and
  usually for a better price. The tracker displays demand from 0 to 10. A displayed 0 is the
  tracker's label.
- **Status** (Stable / Fluctuating / Rising / Dropping / Unstable) reflects whether an item's
  value is currently trending up, down, or holding steady.
- Values generally drop when an item becomes too common, gets nerfed, or loses popularity in
  the meta; event-exclusive items can hold outsized value.
- **Rarity** is the tracker's item-page label (Common, Uncommon, Rare, Legendary, Mythical,
  Godly, Exclusive, Gamepass or Leaderboard).

A displayed Value of 0 is the tracker's figure. A completed-sale price of zero is unconfirmed.

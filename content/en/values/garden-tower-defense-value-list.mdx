## There is no official value list

Garden Tower Defense does not publish an official trading value list. What exist are several
independent, fan-run tracker sites, and their numbers do not always agree — this is normal for
Roblox trading games, where value reflects trader consensus rather than a fixed in-game price.

This page reports a **named source's snapshot at a specific date**, not an authoritative ranking.
Check a live tracker or the game's own community channels before making a trade.

## How to read Demand and Status

Per the source site's own explanation:

- **Demand** shows how many players are looking for an item — higher demand trades faster
  and usually for a better price.
- **Status** (Stable / Fluctuating / Rising / Dropping / Unstable) reflects whether an item's
  value is currently trending up, down, or holding steady.
- Values generally drop when an item becomes too common, gets nerfed, or loses popularity in
  the meta; event-exclusive items can hold outsized value.

## Before you trade

- Cross-check the current price on a live tracker or Traderie listing — this snapshot will go
  stale within days.
